# リーダーの強みと落とし穴 / Leadership Derailer 70

[診断サイトを開く](https://unnkomoresoda.github.io/-leadership-derailer-70/)

70問で任せ方・意見の聞き方・育て方を振り返る、日本語のセルフチェックです。持ち味と空回りしやすい場面を知り、仕事で試す行動を1つ選んで4週間記録できます。

既存の `leadership_derailer_70_v2_1_fixed.html` の設問・採点式を継承し、結果説明を拡張しています。Hogan Assessmentsの公式診断ではなく、標準化された心理検査の精度を示すものではありません。

## 診断内容

- Derailer：11因子 × 5問＝55問
- Leadership Impact：成果基準／自走支援／心理的安全性／育成・忍耐／自己修正の5軸、各3問＝15問
- 3クラスター、上位3因子、8総合アーキタイプの適合度、4注意パターン
- Team Multiplier Index、個別の実践アクション
- 回答見直し、サマリーコピー、JSON保存、印刷・PDF保存

## 利用方法

「70問を始める」を押し、各設問に1〜5で回答して「結果を見る」を押します。未回答があると最初の未回答に移動します。

回答は同じブラウザの `localStorage` に自動保存されます。再訪時は開始ボタンから続きに戻れます。回答リセットは現行・旧形式の回答を両方削除します。任意の表示名とMBTIは別に保持されるため、共有端末では利用後にブラウザのサイトデータを削除してください。

MBTIは任意の組み合わせ解説に使用し、採点には使いません。結果画面の選択欄で変更すると、回答を維持したまま解説を更新できます。回答をサーバーに送信する機能、解析タグ、外部JavaScriptライブラリはありません。GitHub Pagesのアクセス記録等はホスティングサービス側の扱いに従います。

## 採点

回答は1〜5。逆転項目は `6 − 回答` に置き換え、因子・軸ごとの平均を `round((平均 − 1) / 4 × 100)` で0〜100へ変換します。

Team Multiplier Indexは、自走支援25%・心理的安全性30%・育成25%・自己修正20%の加重平均です。成果基準は別軸で表示します。

アーキタイプは8次元（3クラスター＋5軸）の独自プロトタイプとの距離から算出します。適合度、表示帯、注意パターンの閾値はこのページ固有の指標であり、公式HDSのパーセンタイル、人口内順位、発生確率ではありません。採用・昇進・医療などの判断に使用しないでください。

## 開発時の確認

Node.js 20以上で `npm test` を実行します。追加パッケージのインストールは不要です。

ローカル確認は `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。公開後は実際のPages URLで開始・全70問・結果・回答復元・スマホレイアウトを確認してください。

## v2.3 の変更

設問中の因子名・測定意図の説明を削除。全70問をFisher–Yates法でランダム化し、診断途中の再開と見直しでは同じ順番を保持します。リセット後の新しい診断は再抽選します。回答は元の設問IDで保存するため、順番は採点に影響しません。結果には指数の読み方、行動例、強みと注意点、4週間の実践方法を追加しました。

## v2.4 の個別総括

上部の総括はタイプの定型文ではなく、11因子と5軸から生成します。仕事の進め方、判断・自己修正、任せ方・育成、負荷時の反応、実践の焦点の5部分に分け、根拠となる得点を各説明のそばに表示します。警戒と自己修正、精密さと委任、成果基準と育成、距離と異論の聞き取りなどの組み合わせ、支援行動間の差、同点を考慮します。

文章の分岐は振り返り用の独自ルールです（70以上、40未満、支援軸の差20点以上など）。標準化された判定基準ではありません。タイプ算定や得点・設問は変更していません。v2.4時点ではMBTIは表示のみでした。総括はブラウザ内で生成し、サマリーコピー・JSON保存にも含めます。

## v2.5 のMBTIとの組み合わせ

任意で選択した16種類のMBTIについて、外・内への意識、事実・可能性、筋道・価値観、決める・開いておく、の4つの選好を実際の行動得点と照らし合わせて説明します。上部の総括にも組み合わせの説明を追加し、各視点の説明のそばに根拠となる得点を表示します。同じMBTIでも、発想と慎重さ・リスク選好、警戒と自己修正、精密さと自走支援などの組み合わせによって文章が変わります。

MBTIから得点を補正したり、リーダーシップのタイプを変更したりする処理はありません。E/Iを発言量や距離、T/Fを共感能力、J/Pを計画性の優劣と同一視しません。MBTI未選択・保存値が不正な場合は従来の行動得点による総括を表示します。結果画面のMBTI変更はブラウザに保存され、コピー・JSON保存・印刷にも同じ説明が反映されます。過去の回答を再回答する必要はありません。

4つの選好の概念は[Myers & Briggs Foundationの説明](https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/)を参考にしています。タイプは行動や能力を決めるものではありません。このサイトの得点との組み合わせと文章分岐は独自の振り返りルールであり、標準化されたMBTI診断、MBTIの再判定、一致率の測定、診断精度の向上を示すものではありません。

### v2.5.1 の表示順

MBTIの選択欄と4選好の詳しい解説は、「まず、この結果をどう読むか」の直後、「回答に近いリーダーシップの傾向」の前に配置します。

## v2.6 の変更

入口の名称を「リーダーの強みと落とし穴」にし、仕事の具体的な場面で用途を説明します。表示名とMBTIは任意の折りたたみ欄です。設問数、設問、採点式、全70問のランダム化は継承しています。

結果の最初は「あなたの持ち味」「空回りしやすい場面」「今週試すこと1つ」の3項目に整理します。短い要約も行動得点の組み合わせから作り、根拠の得点を併記します。タイプ名やMBTIで固定する処理はありません。詳しい5場面の個別総括、全得点、タイプ、組み合わせ指数は開いて読めます。MBTIの補足は読み方ガイドの直後に保ちます。

行動候補から1つ選び、試す場面と観察する変化を記録できます。1〜4週目の実践状況とメモを同じブラウザに保存し、再訪時は「保存した結果と振り返りを見る」から戻れます。日付は開始日から各週7日後の目安で、通知や自動送信はありません。

取り組みを変えても過去の振り返りは当時の行動・場面・観察項目を保持します。MBTIの変更では入力途中のメモも保ちます。回答リセットは取り組みの記録を削除しません（再び結果を表示するには70問の回答が必要です）。保存を禁止されたブラウザでは保存失敗を表示し、その画面にある記録をJSONに含めて持ち出せます。コピーとJSONには短い要約・詳細・取り組みを含め、印刷には開いている項目が含まれます。

短い要約の分岐は詳細総括と同じく独自の振り返りルールです。検証前の短縮版は追加していません。

v2.6.1では「取り組みの記録を削除」で記録だけを削除できます。70問の回答、表示名、MBTIには影響しません。
