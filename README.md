# リーダーの強みと落とし穴 / Leadership Derailer 70

[診断サイトを開く](https://unnkomoresoda.github.io/-leadership-derailer-70/)

70問で任せ方・意見の聞き方・育て方を振り返る、日本語の独自セルフチェックです。公式HDSではなく、標準化された心理検査の精度を示すものではありません。

## 使い方

70問に回答して「結果を見る」を押します。表示名は任意です。回答と設問順はこのブラウザに自動保存され、回答済みなら「保存した結果を見る」から新しい解説を表示できます。

結果の上部は次の3項目です。

1. あなたの持ち味：仕事の進め方、周囲への関わり、持ち味の活かし方。
2. 空回りしやすい場面：負荷時の反応、得点の組み合わせから見える確認点、対処の助言。
3. 持ち味を活かすアドバイス：提案する理由、実際の伝え方、相手の反応で確かめること。

タイプの固定文ではなく、11因子と5軸の得点、支援行動間の差、複数の傾向の組み合わせから説明します。根拠となる数値は各段落のそばに表示します。同点・中間の回答から強い特徴を決めつけないようにしています。より詳しい5場面の総括と全得点は折りたたみで読めます。

サマリーコピー・JSON保存には3項目の説明と助言、詳細総括、得点を含めます。印刷は開いている項目が対象です。

## 採点と設問

11因子×5問の55問と、成果基準・自走支援・心理的安全性・育成・忍耐・自己修正の5軸×3問の15問、合計70問です。回答は1〜5。逆転項目を `6 − 回答` に変換し、因子ごとの平均を `round((平均 − 1) / 4 × 100)` で指数にします。

チームの自走を支える行動指数は、自走支援25%・心理的安全性30%・育成25%・自己修正20%の加重平均です。8つのリーダーシップ傾向との類似度、3つの反応、4つの組み合わせ指数も表示します。

70問全体をFisher–Yates法でランダムに並べ、途中再開・見直しでは同じ順番を保持します。採点は元の設問IDを使い、順番に影響されません。設問中に因子名・測定意図は表示しません。

指数や文章の分岐（70以上・40未満・支援軸の差20点以上など）は独自の振り返りルールです。人口内順位、偏差値、問題の発生確率を示すものではなく、採用・昇進・医療の判定に使用できません。

## v2.7 の変更

MBTIの入力・解説・保存連携、および「今週の1つを、仕事で試す」の記録フォームを削除しました。アドバイスは上部3項目の中に統合し、得点に応じた説明を拡充しました。長い文章を読みやすい幅で表示し、狭い画面では縦に並べます。

70問、採点、保存済みの回答は継承します。旧版のMBTI・取り組み記録がブラウザに残っていても、読み込み・表示・結果への使用・出力は行いません。入力内容をサーバーに送信する機能、解析タグ、外部JavaScriptライブラリはありません。共有端末では利用後にブラウザのサイトデータを削除してください。

## ファイルと確認

- `index.html`：開始・回答・結果画面
- `app.js`：設問、採点、回答保存、結果表示
- `brief.js`：上部3項目の個別解説・助言
- `profile.js`：詳しい5場面の総括
- `styles.css`：画面幅に応じたレイアウト、印刷対応
- `scoring.test.cjs`：採点・保存・解説・出力の検証

Node.js 20以上で `npm test`。ビルドやAPIキーは不要です。GitHub Pagesは `main` のルートから配信します。
