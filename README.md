# Leadership Derailer 70

[診断サイトを開く](https://unnkomoresoda.github.io/-leadership-derailer-70/)

70問でプレッシャー下の行動傾向とチームへの作用を振り返る、日本語の独自セルフスクリーニングです。

既存の `leadership_derailer_70_v2_1_fixed.html` の設問・採点式を継承し、結果説明を拡張しています。Hogan Assessmentsの公式診断ではなく、標準化された心理検査の精度を示すものではありません。

## 診断内容

- Derailer：11因子 × 5問＝55問
- Leadership Impact：成果基準／自走支援／心理的安全性／育成・忍耐／自己修正の5軸、各3問＝15問
- 3クラスター、上位3因子、8総合アーキタイプの適合度、4注意パターン
- Team Multiplier Index、個別の実践アクション
- 回答見直し、サマリーコピー、JSON保存、印刷・PDF保存

## 利用方法

「70問を始める」を押し、各設問に1〜5で回答して「結果を見る」を押します。未回答があると最初の未回答に移動します。

回答は同じブラウザの `localStorage` に自動保存されます。再訪時は開始ボタンから続きに戻れます。回答リセットは現行・旧形式の回答を両方削除します。任意の表示名とMBTIは別に保持されるため、共有端末では利用後にブラウザのサイトデータを削除してください。

MBTIは表示用で、採点には使いません。回答をサーバーに送信する機能、解析タグ、外部JavaScriptライブラリはありません。GitHub Pagesのアクセス記録等はホスティングサービス側の扱いに従います。

## 採点

回答は1〜5。逆転項目は `6 − 回答` に置き換え、因子・軸ごとの平均を `round((平均 − 1) / 4 × 100)` で0〜100へ変換します。

Team Multiplier Indexは、自走支援25%・心理的安全性30%・育成25%・自己修正20%の加重平均です。成果基準は別軸で表示します。

アーキタイプは8次元（3クラスター＋5軸）の独自プロトタイプとの距離から算出します。適合度、表示帯、注意パターンの閾値はこのページ固有の指標であり、公式HDSのパーセンタイル、人口内順位、発生確率ではありません。採用・昇進・医療などの判断に使用しないでください。

## 開発時の確認

Node.js 20以上で `npm test` を実行します。追加パッケージのインストールは不要です。

ローカル確認は `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。公開後は実際のPages URLで開始・全70問・結果・回答復元・スマホレイアウトを確認してください。

## v2.3 の変更

設問中の因子名・測定意図の説明を削除。全70問をFisher–Yates法でランダム化し、診断途中の再開と見直しでは同じ順番を保持します。リセット後の新しい診断は再抽選します。回答は元の設問IDで保存するため、順番は採点に影響しません。結果には指数の読み方、行動例、強みと注意点、4週間の実践方法を追加しました。

## v2.4 の個別総括

上部の総括はタイプの定型文ではなく、11因子と5軸から生成します。仕事の進め方、判断・自己修正、任せ方・育成、負荷時の反応、実践の焦点の5部分に分け、根拠となる得点を各説明のそばに表示します。警戒と自己修正、精密さと委任、成果基準と育成、距離と異論の聞き取りなどの組み合わせ、支援行動間の差、同点を考慮します。

文章の分岐は振り返り用の独自ルールです（70以上、40未満、支援軸の差20点以上など）。標準化された判定基準ではありません。タイプ算定や得点・設問は変更していません。MBTIは引き続き表示のみで、総括にも使用しません。総括はブラウザ内で生成し、サマリーコピー・JSON保存にも含めます。
